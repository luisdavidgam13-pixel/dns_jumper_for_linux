# DNS Jumper for Linux

A lightweight Bash script to easily switch and optimize system DNS servers on Linux. Built to simplify network configuration directly from the terminal.

## Features
- Quick switching between popular DNS providers (Cloudflare, Google, Quad9, etc.).
- Fast execution directly from the command line.
- Lightweight with no heavy dependencies.

## Prerequisites
- A Linux distribution (Ubuntu, Debian, Fedora, Arch, etc.).
- `sudo` privileges (required to modify system network configurations).

## Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/luisdavidgam13-pixel/dns_jumper_for_linux.git](https://github.com/luisdavidgam13-pixel/dns_jumper_for_linux.git)
   ```

2. **Navigate to the directory:**
   ```bash
   cd dns_jumper_for_linux
   ```

3. **Grant execution permissions:**
   ```bash
   chmod +x dns_jumper.sh
   ```

4. **Run the script:**
   ```bash
   sudo ./dns_jumper.sh
   ```
